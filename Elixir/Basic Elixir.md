# Functional programming
## Immutability
Data is mutable in OOP languages this means, you can change them.
In functional programming everything well data is immutable this means it is not changeable in a way that we kinda clone with each passing function the variable along it to have a safe value:
- Safe value or safe state let us have an easier/safer way to handle data concurrently and parallel: How?
	- Cause we past data not the variable itself so imagine if we have 2 functions trying to access data at the same time, we wouldn't have a problem since we are not accessing the same data we are using it, it is kinda weird idea, but it makes sense in the long run.
